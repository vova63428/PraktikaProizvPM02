# Управление арендой муниципального имущества

Программный комплекс, разработанный в рамках производственной практики по модулю ПМ02. «Осуществление интеграции программных модулей».

## Состав репозитория

- **api/MunicipalPropertyAPI/** – REST API (ASP.NET Core 8, Entity Framework Core)
- **app/MunicipalPropertyClient/** – клиентское WPF-приложение (.NET 8, MVVM)
- **tests/MunicipalPropertyAPI.IntegrationTests/** – интеграционные тесты API (NUnit, WebApplicationFactory)
- **tests/Testq/** – модульные тесты клиента (NUnit, Moq)
- **скрипт/script.sql** – скрипт создания и наполнения БД (Microsoft SQL Server)
- **apicollection/проверка апи.postman_collection.json** – коллекция запросов Postman
- **документы/** – руководство оператора, пояснительная записка, тест-кейсы, отчёт
- **документы с подписями/** – документы с подписями

## Функциональность

- Регистрация и вход пользователей (администратор, сотрудник, бухгалтер, арендатор)
- Управление объектами недвижимости (добавление, редактирование, удаление)
- Управление арендаторами (добавление, просмотр)
- Создание и расторжение договоров аренды
- Внесение и просмотр платежей, учёт задолженности
- Ролевой доступ: каждый пользователь видит только разрешённые данные
- Поиск по договорам, объектам, арендаторам
- Экспорт отчётов в Excel/CSV

## Технологии

- **Сервер:** ASP.NET Core 8, Entity Framework Core, Microsoft SQL Server
- **Клиент:** WPF, .NET 8, MVVM, HttpClient
- **Тестирование:** NUnit, Moq, WebApplicationFactory, Postman, ручные тест-кейсы
